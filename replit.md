# Photo Gallery

This is a plain vanilla HTML, CSS, and JavaScript project. Keep the existing stack and structure; no package manager or build step is required.

## Run

The **Start application** workflow serves the project on port 5000 with:

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

Open the Replit web preview to view the gallery. Edit `index.html` and refresh the preview to see changes.
