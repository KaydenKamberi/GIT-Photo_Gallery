# Photo Gallery

A flower gallery served by a small Express backend. The gallery images are
local files in `Images/`, and each image's description is generated by the
Groq vision API and cached in `descriptions.json`.

## Run

The **Start application** workflow runs the server on port 3000 with:

```sh
npm start
```

Set `GROQ_API_KEY` in the Secrets pane (or a local `.env`) so the AI
descriptions work. Without it the gallery still renders, but each image page
reports that the server is not configured.

## Layout

- `index.html` — the gallery, grouped into a section per color
- `image.html` — single-image page with the AI caption
- `flowers.json` — the list of flowers: filename, display name, alt text, color
- `Images/` — the photos themselves
- `server.js` — Express server and the `/api/describe-image` endpoint

## Adding a flower

1. Drop the photo into `Images/`, named after the flower
   (e.g. `white-lily.jpeg`).
2. Add an entry to the matching color in `flowers.json`.

Both pages read `flowers.json`, so nothing else needs editing. To add a new
color group, add another object to `colors` — the order of that array is the
order the sections appear on the page.
